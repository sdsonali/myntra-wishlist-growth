# README 3 — 10-Slide Deck

## Hard constraints (non-negotiable)
- Max 10 slides
- Font size 14 — everywhere, strictly
- No Fellow name anywhere
- Slide titles = key message, not category labels
- Colorblind-safe colors (avoid red/green as only differentiator; use icons/labels too)
- All linked artifacts (sheets, surveys, live links) must be accessible — test in incognito
  browser before submitting

## Suggested 10-slide structure

1. **Title + Framing**
   "Fixing [specific blocker] to convert high-intent wishlist demand into purchases"
   (not just "Wishlist Conversion Project")

2. **The business metric, broken down**
   Funnel: Add to wishlist → Reconsideration trigger → Confidence resolution →
   Decision → Checkout. Title states which stage you're targeting and why.

3. **How the AI Discovery Engine works** (Part 1's required 1-slide explainer)
   Simple diagram: Scrape reviews/Reddit/YouTube → free LLM tags themes → Aggregate →
   Discovery dashboard. Link to the live engine.

4. **What the discovery engine found**
   Opportunity table — top blockers ranked by frequency %, with 1–2 real (paraphrased,
   not quoted) example patterns per blocker.

5. **Who we talked to and why**
   Target segment definition + interview method (5–6 users, how recruited, what asked).

6. **What primary research confirmed / changed**
   Show the pivot if any — e.g. "AI discovery flagged both fit and price; interviews
   showed fit dominates for [segment]." This slide proves Business Metric → AI →
   Research → Problem convergence.

7. **The problem, precisely defined**
   Segment + product outcome + root cause + existing user workaround + why it matters
   (user value + business value) — all in one tight slide.

8. **The MVP: how it solves this**
   Screenshot of the tool in action + 1-line description of the flow (input → LLM
   answer grounded in real reviews → output). Link to live MVP.

9. **How we'll know it's working**
   North star metric + 2–3 leading indicators + 1–2 guardrail metrics, each with a
   one-line rationale for why it was chosen.

10. **Risks and how we'd de-risk them**
    Top 2–3 risks specific to this solution (not generic) + mitigation for each.

## Design notes
- State the key message in every title (test: could someone understand your whole
  argument by only reading the 10 titles in order? If yes, you're doing it right).
- Use one consistent color/style system across slides — no per-slide redesigns.
- Prefer simple bar charts / funnel diagrams over walls of text.
- Hyperlink: discovery engine, MVP, any interview summary doc — check each link works
  logged out.
